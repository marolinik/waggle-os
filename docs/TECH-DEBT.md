## Adopted Conventions

- Characterization tests live in `*-characterization.test.ts`, pin observed behavior, and mark
  quirks with `// QUIRK (docs/TECH-DEBT.md TD-…)`. They are never edited to make a behavior
  change pass; the behavior change gets its own commit that updates the pin deliberately.
- Structure-only and behavior-only changes never share a commit. A red test mid-refactor means
  revert, not debug.
- Run the suite under Node 22.23.2 before believing a red run.

Phase 3 (clean-code, 2026-09-15) — recorded by the agent from `chat.ts` evidence; the founder ratifies
or amends at PR review of `chore/tech-debt-phase3-chat-clean-code`. Line numbers at `b248ce38`.

- A bare `catch {}` must carry a why-comment naming the consequence of the swallow, and any swallow that changes what the user, the transcript, or the evolution dataset sees must `log.warn` with `{ workspaceId, sessionId }` — the R6-001/W4A structured form at `chat.ts:5703-5707` is the model; silent degradation at 3168, 3633, 3650, 5585, 5790 is the anti-pattern.
- Request-rejection helpers return a discriminated `{ rejection } | { rejection?: undefined; …fields }` result built by one module-level constructor and never throw a second body shape (`chat.ts:104-106` vs the throw at 155 and the six literals at 202-330).
- Error-code strings live in one `as const` block next to `ChatRequestRejection` (`chat.ts:64-67`); no route retypes `'INVALID_FIELD_TYPE'` four times (111, 120, 131, 150).
- Booleans are predicate-phrased (`isPlainInteractiveTurn`, `persistedMemoryReadAllowed`), never imperative or noun (`allowMemoryPersistence` 2660, `toolFreeAdvisory` 2648) and never `should` + noun (`shouldEchoMode` 3278); a name states what it gates, not one of its sources (`litellmAvailable` 3144).
- One name per value inside a handler: a raw request field keeps the `Raw` suffix (`selectedSkillRaw` 2507) and is not re-aliased (`_ws` → `suppliedWorkspace` → `workspace` 2504-2537; `activeSessionId` → `sessionId` 2886); the same rule forbids a validator renaming a field its caller keeps (`retry`/`retryTurn` 101, 2508).
- A repeated conjunction gets a named explaining variable at its third occurrence (`chat.ts:2612-2699` ×5), and a pure predicate over a const is evaluated once (`isCommand` 3199/3277/3278).
- Comments state intent, not history: no ticket/sprint prefixes (`P0-4:`, `Review Critical #3:`), no line-number references (`line 724` 3898, `~1125` 2790, `~L1410` 5849), and a comment that survives a move must still head the statement it describes (1888-1890, 2676-2680).
- Policy literals passed positionally to a named parameter are named constants at module scope, never plugin scope (`streamCannedReply(text, 10)` 3265/3270/3285; Key Decision 2026-09-15 on the plugin-local constant revert).
- Test files restore a swapped seam in `finally` and reset shared state in `beforeEach`, never as the last statement of the test body (`chat-api.test.ts:2387` vs 791-794; 31 inline `resetRateLimiter` calls).
