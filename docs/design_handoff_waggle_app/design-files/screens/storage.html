Three ways a workspace can live

Virtual

managed by Waggle

Files Waggle keeps for you inside the app — no folder to manage. Perfect for quick, throwaway work.

⬡ Only you · session
this one

Local

a folder on your machine

Bound to a real folder you can open in Finder. Your agents read and write the same files you do.

⬡ Only you · on disk

Team

shared, synced

A shared memory + file space for a team — same workspace, role-based access, synced across seats.

⬡ Shared with team

Local-first, always. Memory and files for Virtual and Local workspaces never leave this machine — there's nothing for anyone to leak, subpoena, or sell. Switch a workspace to Team only when you mean to share it, and you can export or delete any workspace, whole, at any time.
